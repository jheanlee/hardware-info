# hardware-info

A cross-platform library for fetching hardware information.

## Supported OSes

`hardware-info` supports the following OSes (sorted alphabetically):

- FreeBSD
- Linux
- macOS
- NetBSD
- Windows

## Related Crates

- [`sysinfo`](https://crates.io/crates/sysinfo) is a cross-platform library for fetching real-time system information,
  such as system resources, processes and networks.
